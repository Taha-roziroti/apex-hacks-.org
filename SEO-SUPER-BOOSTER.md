# SEO Super Booster — Apex Legends Cheats (apexhacks.org)

Implementation playbook for this Astro template. Every item below is **enforced in CI** via `npm run build` (`verify-seo.mjs`, `verify-redirects.mjs`).

## 1. Single canonical host

- `SITE_URL` / `SITE_HOST` in `src/data/site.ts` → `https://apexhacks.org` (apex, no `www`).
- `workers/site.js` and `functions/_middleware.js` → **301** `www` → apex.
- Every HTML page: self-referencing `rel=canonical`, `hreflang=en`, `hreflang=x-default` on the same apex URL.

## 2. Page-level metadata discipline

- One `<h1>` per indexed page; unique `<title>` and `meta description` sitewide (no duplicates).
- `og:title` / `og:description` match `<title>` / description exactly.
- `og:image` + `twitter:image` → `https://apexhacks.org/og/*.jpg` at **1200×630** (`og:image:width` / `height`).
- `rel=image_src` on all indexable pages.
- `robots`: `index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1`.
- No `meta keywords`, no `SearchAction`, no keyword-list JSON-LD.

## 3. Structured data graph

- Shared `@id` `https://apexhacks.org/#product` on home, product, reviews.
- `Organization` + `WebSite` on every page (`siteIdentityGraph()`); `SITE_PURPOSE` states **Apex Legends only**.
- `SITE_ABOUT`: exactly **6** `knowsAbout` terms.
- Product `FAQPage` only on `/faq` (one graph). Reviews: **8** `Review` nodes + `AggregateRating` 4.6 / 8.
- Forums index: `BreadcrumbList`.

## 4. Intent map (not rendered as keywords)

Use `SEO_ROUTE_INTENTS` in `src/data/site.ts` when writing copy. Primary queries:

| Route | Focus |
|-------|--------|
| `/` | apex legends cheats, features, loader status |
| `/apex-legends-cheats` | product, aimbot, ESP, setup |
| `/forums` | setup, ESP, aimbot, EAC patch day |
| `/reviews` | buyer feedback |
| `/faq` | pricing, Windows, delivery |

## 5. Media & thumbnails

- Drop raw gameplay PNGs in `assets/gameplay/` as `images_1.png` … `images_11.png` (order = carousel 1–9).
- Run `npm run prepare:media` → writes `public/media/apex-screenshot-*.webp`, `apex-hero-full.webp`, `apex-cover.webp`, `apex-menu.webp`, `apex-video-thumb.jpg`.
- Self-hosted `/media/apex-*` and `/videos/hero.webm` on home, product, forums.
- `npm run generate:seo-assets` builds all `/og/*.jpg` from those first-party screenshots (run after `prepare:media`).
- Product page: gameplay carousel (`preview-marquee-track`, `apex-screenshot-1.webp`).
- Alt text for each carousel frame lives in `src/data/media.ts` (`PRODUCT_PREVIEW_GALLERY`) — keep descriptions unique for image SEO.

## 6. Sitemap super-boost

- Single `public/sitemap.xml` urlset (not an index); regenerated by `scripts/generate-sitemaps.mjs` on build.
- Every URL includes ≥1 `image:image`; video namespace entry for `/videos/hero.webm`.
- `<?xml-stylesheet href="/sitemap.css"?>` for human-readable view.
- No duplicate hreflang in XML (HTML only).

## 7. Crawl rules

- `robots.txt`: `Sitemap: https://apexhacks.org/sitemap.xml`, `Allow: /sitemap.xml`, `Allow: /videos/`, explicit `Googlebot`.
- `_routes.json` excludes `/sitemap.xml` and `/robots.txt` from Functions.

## 8. Keyword URL aliases (`public/_redirects`)

301 legacy and commercial paths to money pages:

- `/buy-apex-legends-cheats` → `/`
- `/buy-apex-legends-cheat` → `/apex-legends-cheats`
- `/apex-legends-esp`, `/apex-legends-aimbot` → relevant forum threads
- Legacy template paths (`/abi-cheats`, `/dayz-cheats`, …) → `/apex-legends-cheats`
- Retired sitemap filenames → `/sitemap.xml`

## 9. Build commands

```bash
npm run generate:forums   # refresh forum SEO content
npm run generate:seo-assets
npm run generate:sitemaps
npm run build             # full pipeline + verification
```

## 10. Rebrand checklist (new game)

1. Edit `src/data/site.ts` (URL, name, `SEO`, `SITE_PURPOSE`, price).
2. Edit `src/data/games.ts` (slug, feature groups).
3. Run `scripts/generate-apex-forums.mjs` (or game-specific generator).
4. Replace `public/media/apex-*` and hero video.
5. Update `scripts/verify-seo.mjs` host strings if domain changes.
6. `npm run build` until verification passes.
